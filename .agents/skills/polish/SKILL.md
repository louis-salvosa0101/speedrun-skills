# Polish for submission

1. Review the app at mobile and desktop sizes; fix responsive layout problems.
2. Add missing loading, empty, and error states. Fix console errors and obvious bugs without adding features.
3. Write or update `README.md` with what the app does, how to run it, assumptions, and technologies used.
4. Run a production build and resolve failures until it passes.
5. Commit the polish changes with a clear message.
